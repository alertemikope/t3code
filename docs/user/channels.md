# Channels

Channels are project-scoped conversations with a configured agent. Use them for ongoing work that should have a stable name, workspace, agent role, instructions, model, and permission mode.

Open **Channels** from the sidebar. Create a channel by choosing a project and an agent configuration, then send a message to start work. Reply to an earlier message when you want to steer a particular part of the conversation.

Agent configurations are reusable across channels. You can update an agent's role, instructions, provider model, or permission mode from the channel creation panel. An agent can be removed after its assigned channels have been deleted.

Each channel keeps a technical backing thread so provider sessions, checkpoints, and runtime behavior continue to work normally. Backing threads do not appear in the regular thread sidebar, archive, or thread search.

Renaming a channel changes its display name without changing its project or agent. Deleting a channel also deletes its backing thread.
