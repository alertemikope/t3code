# Hide and restore projects

Choose **Hide project** from a project's actions when you want it out of the sidebar without
deleting it. Hiding a project keeps its threads and files, and the project can be restored later.

Open **Settings → Archive** to see hidden projects and archived threads. Choose **Restore** to put a
hidden project back in normal project lists. **Remove permanently** deletes the project entry and
its conversation history, but does not delete the project files on disk.

Archives are scoped to the environment where the project lives. If the same project is connected
from more than one environment, hide or restore the relevant environment entry.
